# Providence Jigsaw: downloads

This repository only holds the downloadable files of **Providence Jigsaw**, a calm, beautiful picture-puzzle game by Glass Providence Games.

**To get the game, go to [providencejigsaw.com](https://providencejigsaw.com).** The game updates itself.

Every release has the same files:

| File | What it is |
|---|---|
| `ProvidenceJigsaw-Setup-<version>.exe` | The Windows installer |
| `ProvidenceJigsaw-<version>-windows-portable.zip` | Windows, no install: unzip and play, saves stay in the folder |
| `*.sha256`, `SHA256SUMS` | Checksums, so a download can be verified |

There is no source code here and nothing to build. Questions and problems: providencejigsaw.com/support.
